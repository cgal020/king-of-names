Gold rules
Light theme. Gold on ivory is {{ goldIvory }}:1, which fails even for large text. Use gold only for the mic fill (with the brand-gold-foreground icon on top), the hairline ring around the mic, and decorative icons that sit next to a text label. Never use it for text of any size on ivory. Dark theme. Gold on near-black is {{ goldDark }}:1. It is primary there, so it's allowed for the mic, buttons, the active tab, links, large display text, the wordmark and icons. Both themes. Keep gold to accents. Body text is always foreground or muted-foreground.
Notes for the build
Destructive buttons use bg-destructive text-background. That's {{ destrLight }}:1 in light and {{ destrDark }}:1 in dark, so you don't need a separate destructive-foreground. Input is the border colour for form fields. It's darker than border so fields meet 3:1; border stays soft for dividers and cards. Recording red is only for the live recording state: the stop button, the ring and the dot. The "Recording" pill text uses destructive on destructive-soft ({{ recPillL }}:1 / {{ recPillD }}:1).

Arabic and Thai fallbacks

Serif stack: DM Serif Display → Noto Naskh Arabic → Noto Serif Thai → Georgia. Sans stack: DM Sans → Noto Sans Arabic → Noto Sans Thai → system-ui. All are on Google Fonts under the OFL. Load the Noto faces with preload: false and the matching subsets so they only download when those scripts appear.

Thai and Arabic need more line height: use at least 1.3× on 24px+ names (for example 24/34, 35/44) on any element that may hold them.

Italic headings in other scripts

Arabic and Thai have no italics. Set font-synthesis-style: none on the root so the browser never slants them; they render upright in the Noto face while Latin in the same line stays italic.

For people's names, wrap each name in <bdi dir="auto"> (or use unicode-bidi: plaintext) so an Arabic name doesn't reorder the punctuation and dates around it.

The wordmark

"KING OF NAMES" is DM Sans 500 at 12/16, tracked +0.30em, uppercase, set as live text (not a font small-caps feature). It's paired with the crown glyph at 22×15 with a 1.6px stroke. Colour is brand-ink in light and brand-gold in dark. It should never be larger than a section label: the app stays discreet.

Map (Mapbox)

Recommendation

Start with Mapbox Standard: lightPreset: "day" in light, "night" in dark, switched by the same prefers-color-scheme listener. Use the "monochrome" (or "faded") theme so the map recedes behind the pins. Turn off POI and transit labels, and set the water, greenspace and road colour overrides below wherever your GL JS version exposes them. That gets close enough for pins and clusters to read correctly, with no style to maintain.

Move to a custom Studio style (two: Ivory and Night) only if the land tint has to match the app background exactly. You'll need these anyway for static images, so it's a small step.
